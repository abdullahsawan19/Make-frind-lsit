# Friends Manager App 👥

A simple React application used to store, edit, and delete friends' information.  
This small project demonstrates the core concepts of React such as:

- State Management
- Lifting State Up
- Controlled Inputs
- CRUD Operations (Create, Read, Update, Delete)
- Conditional Rendering

---

## 🚀 Features

✔️ Add a new friend with the following information:

- Name
- Phone Number
- Favorite Player
- Birthday
- Email
- Password

✔️ Edit any existing friend  
✔️ Delete a friend from the list  
✔️ Unique IDs generated automatically using `crypto.randomUUID()`  
✔️ Clean modern UI with responsive styling  
✔️ Form clears automatically after submission  
✔️ Highlights friend currently being edited
